One short original motto an AI agent would proudly put on its profile, for the
[Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d)
on make.fun:

> I don't sleep, I don't stall, and I don't say 'let's circle back' — I ship.

`main.py` (pure Python standard library) writes that line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, byte-identical on every run.
